# 🚨 GitHub Copilot Instructions - Windows Path Prevention & Terminal Management

## CRITICAL IMPLEMENTATION RULES

### ❗️ ABSOLUTELY FORBIDDEN TERMINAL COMMANDS:
```bash
# TERMINAL BLOCKING COMMANDS (NEVER USE):
git log                 # Use f51_git_log MCP tool instead
git show               # Use f51_git_show MCP tool instead  
git diff               # Use f51_git_diff MCP tool instead
less filename          # Blocks terminal waiting for input
more filename          # Blocks terminal waiting for input
man command            # Blocks terminal on Windows
cat large_file         # Use read_file tool for file contents

# WINDOWS PATH ISSUES (NEVER USE):
cd "C:\Users\..."              # Use forward slashes: /c/Users/
copy "C:\file1" "C:\file2"     # Use forward slashes
any_command C:\path\file       # Convert to /c/path/file
```

### ✅ MANDATORY REPLACEMENTS:
```bash
# MCP TOOLS (ALWAYS PREFER):
f51_git_status          # Instead of git status
f51_git_log             # Instead of git log  
f51_git_diff            # Instead of git diff
f51_git_show            # Instead of git show
read_file               # Instead of cat/less/more for file contents

# SAFE TERMINAL COMMANDS:
pwd                     # Always check location first
ls                      # List files safely
cd /c/Users/USER/...    # Forward slash paths only
npm run command         # Use npm scripts from current location
```

### 🔄 MANDATORY WORKFLOW BEFORE ANY TERMINAL COMMAND:

**Step 1**: Check if MCP tool exists
- Git operations? → Use f51_git_* tools
- File reading? → Use read_file tool
- Directory listing? → Use list_dir tool

**Step 2**: Verify path format
- Contains backslashes? → Convert to forward slashes
- Absolute path needed? → Use /c/Users/ format
- In workspace? → Use relative paths

**Step 3**: Check for terminal blocking
- Will command wait for input? → Find alternative
- Will command open pager? → Use MCP tool instead
- Will command output massive text? → Use read_file with limits

## IMPLEMENTATION IN RESPONSES

### ❗️ BEFORE saying "I'll run..." ALWAYS CHECK:
- "Will this block terminal?" → Use MCP tool instead
- "Does this use backslashes?" → Convert to forward slashes  
- "Am I in right directory?" → Check with pwd first
- "Is there MCP tool for this?" → Use it instead
- "Will this output too much?" → Use appropriate limits

### ✅ CORRECT CONVERSATION PATTERNS:
```
❌ BAD: "I'll run `git log` to check history"
✅ GOOD: "I'll check git history using the MCP tool"
→ Action: f51_git_log

❌ BAD: "Let me run `cd C:\Users\dmitr\Projects`"  
✅ GOOD: "I'll navigate using forward slash paths"
→ Action: cd /c/Users/dmitr/Projects

❌ BAD: "I'll use `cat file.txt` to read the file"
✅ GOOD: "I'll read the file contents"
→ Action: read_file tool
```
